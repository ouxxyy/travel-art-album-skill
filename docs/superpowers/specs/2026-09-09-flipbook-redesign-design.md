# 翻页交互重设计

## 设计批准来源

用户在 MYW-51 明确反馈现有翻页效果差，要求参考 `HaichaoLihc/create-photo-flipbook-ui` 重做，并要求三种艺术风格都可选、可混排。本文把这项明确反馈视为设计方向批准，不扩大到 3D WebGL、在线服务或批量生图。

## 来源结论

参考仓库固定在 commit `53a9df7d5b13ef2d7a1f6bf5011c1fad570e021c`。2D、3D 和媒体不再被产品策略默认排除：可进入研究、原型、交互或最终私人画册，但每项仍须核清自身许可或权利来源。根目录 MIT 许可证覆盖原创项目代码与 installable skill；README 对 `examples/3d-book-1/` 改编代码和媒体作了许可保留，因此它们不能仅凭根许可证进入可分享包。

参考 runtime 和本项目 vendored StPageFlip bundle 的 SHA-256 都是 `bbaca0bbef57a22bb66a3fc69d67baf9a17fb9a9c89ec9ed35e2b91abe4bd1e7`。质量差异来自外围舞台、页面材质和状态交互，而不是翻页库版本。

## 方案比较

1. **采用：3D Book 2 体验契约 + 独立 Three.js 曲面书页。**复用其 MIT 覆盖的正交相机、白色舞台、动态阴影、边缘预览和交互思路；翻页几何独立实现，避免直接分发许可链不完整的传递依赖。
2. MIT 2D runtime 契约 + 单文件改造。离线最轻、兼容更广，但实体曲面与光影弱于用户指定的 3D 参考效果，可保留为后续低性能回退方向。
3. 原样打包 Quick FlipBook 示例。最接近参考代码，但其 `three.modifiers` 依赖未随 npm 包提供明确许可证全文，不进入当前可分享原型。

## 交互与视觉

- 舞台采用 3D Book 2 的明亮正视正交构图，书页在白色桌面上产生克制动态阴影。
- 每一物理叶包含正反两张页面纹理，围绕书脊旋转；翻页中对细分顶点施加曲率，形成真实抬起、弯折和落下过程。
- 封面、环衬、三种风格示意页、版权页、封底形成完整书序；示意页仍明确标注为占位，不冒充真实样片。
- 页面边缘 hover 轻抬；点击左右半区、水平拖拽/触摸、圆形按钮、方向键、空格、Home/End 均可操作。
- 目标页状态天然形成输入队列，快速连续输入不会在动画期间丢失。
- `prefers-reduced-motion` 下自动翻页近乎立即完成，并取消 hover 预览。

## 三种风格与制作清单

三种风格始终可用，不再要求整册只能选一种。进入样片环节时必须向用户提问：

1. 选择“整册统一”或“逐张混排”。
2. 若统一，确认默认风格；若混排，先为每张照片给出推荐风格，再展示有序清单让用户逐张确认或覆盖。

制作清单每张照片记录：`source_path`、`source_fingerprint`、`order`、`orientation`、`style`、`style_version`、`style_confirmed`、`artwork_path`、`attempts`、`qa_status`。其中 `style` 只能是 `impasto-miniature`、`isometric-healing-blocks`、`papercraft-travel`；任何 `style_confirmed !== true` 的照片都不得进入批量生成。

## 测试

- 静态契约：单文件内嵌脚本/CSS/占位纹理、Three.js 与参考项目许可、曲面顶点更新、动态阴影、混排风格元数据和私有素材排除声明存在。
- 浏览器：`file://` 打开且 0 HTTP(S) 请求；WebGL renderer 成功；页面点击/拖动、Pointer touch、按钮、键盘、Home/End；快速正反向输入；首页末页边界。
- 性能：记录未压缩/压缩后 HTML 大小、首次 ready 时间、静止时 requestAnimationFrame 停止、像素比和几何细分上限。
- 视觉：生成桌面封面、桌面展开、移动单页截图并检查曲面、阴影、裁切、控件和可读性。自动化截图只作证据，不替代人工查看。

## 门禁

本轮只重做离线占位原型和 skill/制作清单契约。允许有权使用的 2D、3D 与媒体资源进入后续画册，但私有原图、私人画册和未经许可的示例媒体不得进入分享安装包。没有用户真实照片，不生成九张样片；没有保存用户对逐张风格与人物效果的确认，不进入批量生图。
