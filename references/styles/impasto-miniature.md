# 厚涂微缩

来源：GZ-L/photo-to-poster-skills 的 `impasto-miniature-landscape`，MIT，固定 commit 见 `docs/source-license.md`。

将对应原图完整重构为明亮、立体、有触感的 3:4 厚涂微缩场景。人物数量、身份特征、服装、主要动作、相互关系和地点标志优先保持；人物抽象程度必须低于环境，熟人辨识优先于材质夸张。横图先分析人物与环境关系，再重组到竖幅，禁止硬裁掉人物。

使用明亮暖白纹理纸与充足留白，以源照片中的路径、水面、地形或光带形成半透明厚涂承托。保留刮刀纹、堆叠颜料、隆起边缘与手塑感；颜色从原图提取，可提亮和净化，但不强塞固定色卡。可清理路人和杂物，不得新增主体或改变旅行事实。

画面内不生成标题、字母、编号、水印或伪文字；书名和说明只由 HTML 排版。
