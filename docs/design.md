# 阶段一设计冻结

## 范围

本阶段只交付：来源与许可记录、当前宿主能力检查、三份去除图中文字要求的风格规范、以及使用占位图的封面/两页/封底单文件翻页原型。九张真实小样需要用户提供代表照片后生成；批量阶段由用户验收一硬门禁保护。

## 方案比较

1. **StPageFlip 2.0.7 内嵌（采用）**：实体翻页最成熟、MIT、无运行时依赖；代价是需保留许可，且要针对末页边界做外层按钮保护。
2. CSS 3D 自研：体积小、完全可控；但触摸、快速翻页和跨浏览器边界风险高，不符合“复用成熟能力”。
3. 多文件静态站：调试简单；但不符合单文件离线分享要求。

## 边界与数据流

`照片文件夹（只读） → 清点/方向/指纹 → 用户确认信息 → 三图×三风格小样 → 用户验收一 → 逐图生成与检查 → 制作清单 → HTML 构建 → 离线/浏览器检查`

图像工具适配层由宿主智能体承担；脚本层只负责确定性的清点、状态和画册构建。制作清单是两者之间唯一契约，避免画册脚本访问原图或编造叙事。

## 原型交互

桌面为双页展开，窄屏为单页；支持点击按钮、左右方向键和 StPageFlip 自带鼠标/触摸翻页。页码由 flip 事件更新。`prefers-reduced-motion` 下将翻页时间降到最短可用值。所有 CSS、SVG 占位图和 JavaScript 均内嵌，禁止外部请求。

## 错误与门禁

- 没有参考图编辑能力：停止，不降级为无参考的文本生图。
- 没有用户照片：只交付占位原型，不能把占位图称为小样。
- 许可不明：只记录设计启发，不复制代码或资产。
- 末页/首页：按钮在边界禁用，避免已知上游越界风险。
- 用户验收一未保存：批量命令必须拒绝运行（后续阶段实现）。
