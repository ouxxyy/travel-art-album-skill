# 等距治愈积木

来源：GZ-L/photo-to-poster-skills 的 `isometric-healing-blocks`，MIT，固定 commit 见 `docs/source-license.md`。

把对应原图重构为柔和的 3D/等距模块雕塑。保留人物数量、身份、面部关键特征、服装、动作、体量比例、遮挡与空间关系；人物保持足够具象，环境才可进一步块面化。横图必须先理解主体关系再适配 3:4，禁止机械裁切。

模块可堆叠、穿插、嵌套，边角圆润，材质为哑光纸浆、木、粉蜡或柔性材料，阴影轻柔。每张从自身原图提取主色、明暗和冷暖关系，适度提亮去浊，不使用统一固定色卡。允许优化杂乱背景，但不得变成乐高复刻、像素化、塑料玩具或电商陈列。

画面内不生成标题、字母、编号、水印或伪文字；书名和说明只由 HTML 排版。
