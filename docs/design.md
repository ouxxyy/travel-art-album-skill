# 阶段一当前设计

## 范围

本阶段交付来源/许可记录、宿主能力检查、四份无图内文字的风格规范、逐张风格制作清单契约，以及使用自制占位纹理的单文件 3D 翻页原型。没有用户真实照片，不生成十二张样片；用户验收一仍是批量生图硬门禁。

## 交互选型

1. **当前采用：Three.js 独立曲面书页。**对照 HaichaoLihc/create-photo-flipbook-ui 的 3D Book 2，采用正交相机、白色舞台、正反页面、顶点弯折、动态阴影、边缘预览、拖拽和按需渲染。Three.js 为 MIT；当前 HTML 约 543 KiB。
2. **允许使用：StPageFlip 2D。**兼容面更广、体积更小，可作为低性能或无 WebGL 宿主的后续构建选项，不再是当前原型默认实现。
3. **条件允许：参考仓库 3D 示例与媒体。**产品不默认排除；进入研究、原型、交互或私人最终画册前，逐项核实许可证或用户权利。私有原图、私人画册与无权分发的示例媒体不得进入分享包。

当前不打包 Quick FlipBook/`three.modifiers`，因为后者 npm 包缺少许可证全文且 SPDX 仅写模糊的 `BSD`。曲面翻页几何由本项目独立实现。

## 数据流

`照片文件夹（只读） → 清点/方向/指纹 → 用户确认书名 → 三图×四风格小样 → 询问统一或混排 → 逐张确认 style → 用户验收一 → 批量生成与检查 → 制作清单 → HTML 构建 → 离线/浏览器检查 → 打印/导出 PDF 检查`

制作清单是生图与画册构建之间的唯一契约。四种风格始终可用；每张记录 `style`、`style_version` 和 `style_confirmed`。只有逐张确认且 `user_acceptance_one: true` 时，`npm run validate:batch-ready -- <实际清单>` 才能通过。

## 原型交互

翻页以"接近实体书"为标准：拖拽完全跟手，按住即悬停；松手时书页质心未过书脊（约半页）则随欠阻尼弹簧轻抬回位，越过质心或真实甩动才像受重力一样加速落页并轻微落定过冲；动画途中抓页会无缝继承当前翻页进度。弯折叠加页角扭转与静止纸弧，页面不再是完美平板。支持页面左右点击、鼠标拖拽、原生触摸、圆形按钮、方向键、空格、Home/End。快速输入更新弹簧目标，不因动画丢失。静止后 requestAnimationFrame 停止；减少动态效果模式禁用 hover 预览并快速落页。边缘预览采用掀起快、收回慢的差速缓动。

无 WebGL 时不继续初始化，也不抛未捕获异常；页面显示明确静态提示。最终构建器可在后续阶段选择 2D 输出，本阶段不伪装 3D 已运行。

## 错误与门禁

- 没有参考图编辑能力：停止，不降级为无参考文本生图。
- 没有用户照片：只交付占位原型，不能把占位纹理称为样片。
- 许可或媒体权利不明：可以研究，但不能进入可分享产物。
- 无 WebGL：显示提示并停止 3D 初始化；不得宣称 3D 支持。
- 用户验收一未保存：`--batch-ready` 必须拒绝运行。
